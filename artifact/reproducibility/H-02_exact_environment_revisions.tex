\subsection{Numerical environment and model revisions fixed before execution}

The pinned CPU environment used Python 3.10.19, NumPy 2.2.6, pandas 2.3.3,
scikit-learn 1.7.2, XGBoost 3.1.3, and TabPFN 7.0.0; TabPFN used its GPU
implementation.  The TabPFN dose extensions used PyTorch 2.11+cu128 with the
same numerical pins, while paired HistGradientBoosting used the CPU
environment.  Extraction used PyTorch \texttt{2.12.0.dev20260408+cu128} and
Transformers 5.12.0, with one greedy generation (\texttt{do\_sample=false}, at
most 8,192 tokens) and no thinking, tools, or retrieval.  Cached revisions were:
