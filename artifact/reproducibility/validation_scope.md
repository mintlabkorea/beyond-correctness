# Validation scope

make verify: all mapped quantitative evidence and selected prose, human agreements and final utility/check derivations, candidate inventory hashes, D.2 means, bootstrap/coverage exceptions and recorded environment versions. Missing evidence and mismatches fail. Final content support is checked against the new four-row adjudication record, the initial sheets and the separate C01-B author-supplied decision. The verifier authenticates internal consistency, not the occurrence of a human meeting or a historical timestamp.

make scan: all distributable files, generic private paths/identifiers/secrets/structured row records, nested XLSX XML/relationships/author properties and PDF author metadata (pdfinfo if available). The local finalization scan additionally uses private repository-identity fingerprints, which are never redistributed. Pattern checks do not mathematically prove all possible private strings absent.

make validate: scans; all 36 paper-item mappings and inputs; prompt/response and seven extraction hashes; checksum/manifest integrity; numerical verification; exact equality between remaining PARTIAL promise names and the disclosed reconstruction-limitations list. Any new or undisclosed incompleteness fails. JSON separately reports full_reconstruction_completeness=PARTIAL.

python3 reproducibility/validate_artifact.py --require-full-completeness: additionally requires no PARTIAL or MISSING promise. It is expected to fail for L01–L03; this behavior is tested and not described as completed reconstruction.

The manifest excludes itself and SHA256SUMS. SHA256SUMS covers every file except itself. Fresh extraction and reviewer commands are tested before release; validation after optional output regeneration requires a fresh extraction if generated bytes changed.

Python scanning also checks decoded literal/concatenated/joined strings using AST parsing without execution. The local independent anonymity audit uses a separate private-pattern source and a separate ripgrep search, and checks extracted PDF text as well as workbook XML. The actual excluded verifier is retained only outside the archive as a regression input; it must be detected by the independent audit. Third-party citation authors are manually reviewed exceptions, not blanket substring suppression.
