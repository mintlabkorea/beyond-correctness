# Independent second AI coder protocol v1

Requested 2026-09-08, after primary design and outcome freezes. Primary v1 remains authoritative and unchanged; this is a reproducibility/sensitivity exercise, not outcome-informed adjudication.

## Information separation

A fresh agent with no inherited conversation receives only the copied CONTROL_CODING_RULE_V1, factual construction v1.1, and source papers (plus their layout text). It is instructed to read only its packet, never the parent repository, memory files, primary scopes/codes, outcomes or summaries. The packet manifest identifies TARTE's preacceptance mirror as corroborative only. The workspace is shared: this is an instructed information boundary with auditable supplied files, not an OS-enforced sandbox or proof of statistical independence. Source PDFs themselves contain published results, so no literal outcome blindness is claimed. Outcomes must not be extracted or used in design coding.

The second coder is a separate AI agent using the inherited model, not an independent human expert. Shared model, rule, source papers and the first auditor's factual-construction sheet can induce correlated judgments. Do not market this as human inter-rater validation or complete independence from primary fact selection.

## Independent task

All 25 fixed comparisons, without study selection. First independently declare tested semantic use and protected observations, metadata, representation and predictive setup. Write and hash the scope sheet before assigning gates. Then assign Removal / Preservation / Interface (Pass / Fail / Unclear), with source location and rationale per gate. Derive utility admissibility mechanically: Yes iff all Pass; No if any Fail; Unclear otherwise. Record ambiguities, source-access constraints and incidental result exposure. Freeze the second coding before opening primary codes for comparison. No feedback about primary verdicts is sent during coding.

No primary CLAIM_SCOPES, operational addendum, CLAIM_IDENTIFICATION, derived control labels or outcome artifacts are supplied. The common rule is exactly the user-requested CONTROL_CODING_RULE_V1; primary auxiliary operational guidance is not silently added to the second coder's packet. Differences can therefore reflect independently chosen scope/protection and operational interpretation, not only gate classification.

## Prespecified comparison

Report gate-specific exact agreement n/25, percent agreement, disagreement count and full 3×3 confusion tables. Report the same for admissibility. No kappa-only headline; kappa is optional and not necessary for this small, prevalence-skewed set. Rows share studies/arms and are not independent trials; no binomial confidence interval or significance test is planned.

Disclose every comparison with the two scopes/protected sets, all gate verdicts and admissibility, and source-backed rationales for disagreements. Scope/protected-set text is independently declared free text: exact wording equality is not semantic agreement, so do not invent a numerical semantic-agreement score.

Headline sensitivity: compare (a) counts of Yes/No/Unclear admissibility among 25 comparisons and (b) counts of nine studies with at least one Yes, only Unclear/No but at least one Unclear, or all No. List studies and comparisons whose status changes. This uses design codes only; do not merge outcomes into second-coder claims or select whichever coding produces stronger findings.

Differences are descriptive and unadjudicated. A suspected factual error is documented separately for later source verification; only a demonstrated factual error warrants a versioned addendum. No automatic addendum or primary overwrite from disagreement. Prepare supplement-ready standalone material without editing the manuscript's primary results.
