For continuous items report valid_codes as [] and ordinal_direction
"higher_is_more" or "higher_is_less" for the measured quantity.

`ordinal_direction` describes what a LARGER code number means for the quantity
the item measures: "higher_is_more" if a larger code means more of it,
"higher_is_less" if a larger code means less of it, "unordered" if the codes
are categories with no magnitude ordering.

`requires_reverse_coding` -- operational rule, applied uniformly.  First name
the quantity or state the item measures (a diagnosis item measures the
condition being PRESENT; a difficulty or dependency scale measures the
difficulty or dependency itself).  Set requires_reverse_coding = true exactly
when a numerically larger valid code corresponds to LESS of that quantity or
to the state being ABSENT.  This applies to binary items too: if the code for
"yes / present" is smaller than the code for "no / absent", the item requires
reverse coding.  Never mark a yes/no item "unordered" as a way of skipping
this decision.

Set `basis` to "documentation" only when the supplied codebook text determines
your answer, and to "prior" when you are relying on knowledge of the
instrument.
